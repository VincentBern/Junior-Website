In four steps

  1. Download Junior with the button above. You get a file named Junior.mcpb.
  2. Double-click the file. Claude Desktop opens and offers to install Junior: click Install.
  3. Write to Junior in a new conversation. It opens a sign-in page: choose the Google address registered for your mandate. If you work for more than one business, choose the one for this mandate.
  4. Go back to Claude. Junior welcomes you and suggests where to start.
